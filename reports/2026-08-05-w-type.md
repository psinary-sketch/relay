## §1 — THE Π₁ FILING (CLASSICAL-AT-CITE)

**The arithmetic form, at cite.** RH has elementary arithmetic equivalents. **Lagarias
(2002):** RH ⟺ σ(n) ≤ H_n + exp(H_n)·log(H_n) for every n ≥ 1 (strict for n > 1) — a
modification of **Robin's** criterion, and elementary in the strict sense that it involves
only the divisor sum, the harmonic numbers, exp and log
([Lagarias, *An Elementary Problem Equivalent to the Riemann Hypothesis*](https://dept.math.lsa.umich.edu/~lagarias/doc/elementaryrh.pdf);
[the Robin-line reformulations](https://arxiv.org/pdf/1110.5078)).

**The type.** Each instance is a decidable statement about a single integer n (σ(n) and H_n
are computable; the inequality is checkable to sufficient precision), so RH in this form is a
universally quantified statement over decidable instances — **Π₁**.

**The consequence, stated once, as the classical logic it is.** A false Π₁ statement has a
counterexample, and that counterexample is a finite object whose failure can be exhibited and
checked — so **false ⟹ refutable** (in any system that verifies the arithmetic of the
instances). Contrapositive: **if RH is independent of such a system, then RH is true.**
Hence — and this is the only inference filed — **unprovability evidence is weak evidence FOR
the statement, never against it.** (Weak, because independence-of-a-fixed-system is not the
same as unprovability, and no independence result for RH exists; the inference is about what
such a result *would* license.)

**The consequence for THIS arc's null branches, spelled out as required.** The era filed
several nulls — the currency's, the determinacy verdict's, the barriers'. **None of them is
evidence against RH, and the Π₁ form is why:** each null says a *method* cannot reach the
statement, and a method's failure on a Π₁ statement leaves the statement's truth untouched
while removing a route. The arc's nulls therefore accumulate as **route-eliminations**, and
the Π₁ filing is the standing reason they can never accumulate into doubt about the object.
**No RH claim of any kind is made here** — not that it is true, not that it is provable, and
not that independence is likely.

the Silence Principle's inclusion is a resemblance the test does not confirm. READING grade,
