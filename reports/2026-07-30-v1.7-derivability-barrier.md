## What was committed

`Kernel/Cascade/InvarianceBarrier.lean`, same module as the v1.6 lemma, same discipline — **general form
only**: arbitrary carrier, arbitrary agreement relation, arbitrary property, arbitrary witness pair;
derivability not truth; **no ξ/Epstein instantiation, no RH content in name or statement**.

```
def Derives (agree : α → α → Prop) (P : α → Prop) (x : α) : Prop :=
  ∀ z, agree x z → P z

theorem derivability_barrier
    {agree : α → α → Prop} {P : α → Prop} {x y : α}
    (h_agree : agree x y) (h_fail : ¬ P y) :
    ¬ Derives agree P x :=
  fun h_der => h_fail (h_der y h_agree)
```

The distinction the Tier-1 pass forced, now compiled: `invariance_barrier` needs the divergence biconditional
`¬(P x ↔ P y)` (which at (ξ, Z) would require knowing RH); `derivability_barrier` needs only one agreeing
counter-witness `¬ P y` — no knowledge of `P x`. This is the manuscript's operative terminal.
