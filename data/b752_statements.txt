     16  
     17  The main result in this file is `DirichletCharacter.LFunction_ne_zero_of_one_le_re`:
     18  if `χ` is a Dirichlet character, `s ∈ ℂ` with `1 ≤ s.re`, and either `χ` is nontrivial or `s ≠ 1`,

     22  `riemannZeta_ne_zero_of_one_le_re` (which does not require `s ≠ 1`, since the junk value at `s = 1`

     24  
     25  These results are prerequisites for the **Prime Number Theorem** and
     26  **Dirichlet's Theorem** on primes in arithmetic progressions.
     27

     29  
     30  We split into two cases: first, the special case of (non-trivial) quadratic characters at `s = 1`;
     31  then the remaining case when either `s ≠ 1` or `χ ^ 2 ≠ 1`.
     32  
     33  The first case is handled using a positivity argument applied to the series `L χ s * ζ s`: we show
     34  that this function has non-negative Dirichlet coefficients, is strictly positive for `s ≫ 0`, but
     35  vanishes at `s = -2`, so it must have a pole somewhere in between.
     36  
     37  The second case is dealt with using the product
     38  `L(χ^0, 1 + x)^3 L(χ, 1 + x + I * y)^4 L(χ^2, 1 + x + 2 * I * y)`, which
     39  we show has absolute value `≥ 1` for all positive `x` and real `y`; if `L(χ, 1 + I * y) = 0` then
     40  this product would have to tend to 0 as `x → 0`, which is a contradiction.
