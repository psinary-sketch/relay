*** ### THE RULE, FILED: ### **NO ONE-LINE CHECK IS READ UNTIL IT HAS FAILED ON A FIXTURE IN
### THE SAME RUN.** ### A CHECK THAT HAS NOT BEEN SEEN TO FAIL HAS NOT BEEN SEEN TO WORK. ***

COMPONENT 1 -- (P1) THE TOOL.
----------------------------------------------------------------------------------------------------
### relay tools/check_harness.py. WHAT IT DOES:
 · a check is passed as a CALLABLE or a SHELL LINE with a MUST-FAIL fixture;
 · ### THE FIXTURE RUNS FIRST AND THE CHECK IS **NOT RUN AT ALL** IF THE FIXTURE PASSES;
 · ### IT ASSERTS ITS CWD IS THE DECLARED REPO ROOT and raises CwdError if not --
   ### b209's WRONG-REPO PUSH AND b216's WRONG-CWD LOOP ARE ONE SPECIES AND THIS IS WHERE IT DIES;
 · ### ANY EXCEPTION IS A LOUD ERROR, printed whole, never swallowed and never silently
   converted to a FAIL -- ### AN ERROR MEANS THE CHECK DID NOT REPORT ON THE OBJECT AT ALL,
   which is a different thing from reporting badly;
 · ### AN EMPTY STDOUT IS A **FAIL**, NOT A PASS. ### That one line is b216's instance;
 · a non-bool return is an ERROR, not silently truthy;
 · it EMITS ITS OWN AUDIT BLOCK via audit_emit, so its verdicts are not prose.

### FIXTURES ON THE HARNESS ITSELF, BOTH POLARITIES: ### **12 OF 12.**
   the ordinary case (honest fixture, check passes) -> PASS
   ### THE CASE THE FERRY NAMED: the fixture WRONGLY PASSES -> **REFUSED**
   the fixture ERRORS -> REFUSED (an errored fixture licenses nothing)
   honest fixture, check genuinely fails -> FAIL
   ### empty stdout -> FAIL (b216 in one row)
   working shell check + failing shell fixture -> PASS
   check raises -> ERROR;  check returns a non-bool -> ERROR
   ### the WITNESS rows (added mid-act; see Component 2): witness cannot pass -> REFUSED;
     witness errors -> REFUSED; both guards honest -> the check is read
   ### the CWD assertion, tested by violating it -> raises
*** ### AND THE COUNTS ARE THE HARNESS BEHAVING CORRECTLY, NOT A CLEAN RUN: 3 pass, 2 fail,
### 2 error, 4 refused. ### A HARNESS FIXTURE SUITE THAT REPORTS ALL-PASS HAS NOT TESTED THE
### REFUSAL PATH, WHICH IS THE ONLY PATH THAT MATTERS. ***
