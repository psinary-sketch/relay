----------------------------------------------------------------------------------------------------
### ### **THE ORDER ALLOWS TWO OUTCOMES AND FORBIDS BOTH**, and says the choice is made by ### **WHAT
### ### THE TRACKED PATH CAN ACTUALLY CARRY.**

### repository hold the guard, and does the repository then RUN it? ### **IF IT RUNS AND REFUSES AND
### ### ALLOWS CORRECTLY, THE ITEM IS MADE DURABLE. ### IF IT CANNOT, THE ITEM IS STRUCK WITH THE
### ### REASON.**
### ### **WHAT DURABLE MEANS HERE, EXACTLY, AND IT IS LESS THAN IT SOUNDS:** ### `core.hooksPath` is
### LOCAL CONFIG. ### **A CLONE STILL RUNS NO HOOK UNTIL SOMEONE SETS IT.** ### What changes is that the
### GUARD ITSELF travels with the clone instead of living only on this machine, so the residual step is
### ### **ONE CONFIG COMMAND AND NOT A FILE NOBODY HAS.** ### **THE RESIDUAL MANUAL STEP IS NAMED IN THE
### ### BANK AND IS NOT DESCRIBED AS ZERO.**
### ### **EXERCISED IN BOTH POLARITIES IN EACH REPOSITORY:** ### a push from a non-`push-*` branch must
### be REFUSED and a push from a `push-*` branch ALLOWED, under `--dry-run`, head and remote unmoved.

### ### **THE EXERCISER IS AN OWNER INSTRUMENT AND MUST FOLLOW THE GUARD.** ### `tools/b304_hooks.py`
### reads the old location; if the guard moves and the exerciser does not, ### **THE RECORD KEEPS
