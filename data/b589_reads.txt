    :1      # rowgen — Correspondence row generator + differ
    :2      
    :3      A **public** tool. It emits from **kernels** (Lean declarations at pins), never from papers — there is no
    :4      research content here, only mechanical facts about compiled terminals.
    :5      
    :6      ## What it produces
    :7      
    :8      **Mode `generate`** — for each terminal `{name, repo, pin, module, file}`, a record:
    :9      - `check` — the `#check @name` statement, verbatim (via `lake env lean`).
    :10     - `axioms` — the `#print axioms name` line, verbatim (NOT rounded — `[propext]` stays `[propext]`).
    :11     - `doc` — the declaration's docstring first paragraph, verbatim (from source at the pin).
    :12     - `body1` — the proof body's first line.
    :13     - `defenc` — **DEFINITION-ENCODED** flag: true if any definition named in the conclusion has a body that
    :14       is a literal constant (`:= 0`, `:= true`, `:= 1`, …) or `True`. This is what catches a stand-in
    :15       (e.g. `topological_constant`, whose conclusion references `topological_contribution := 0`).
    :16     
    :17     **Mode `diff`** — given a paper's Correspondence table (markdown) and the records, it flags each row whose:
    :18     - **Status contradicts the docstring** (row says DERIVES; doc says stand-in / encoded / placeholder / deprecated / assigns),
    :19     - **profile is rounded** (row reads axiom-free while the record shows `[propext]` or more),
    :20     - **pin is stale** (the commit in the row ≠ the record's pin),
    :21     - **cited terminal no longer exists** (a configured terminal fails to resolve at its pin),
    :22     - **is definition-encoded yet graded DERIVES** (defenc true but the row reads DERIVES, not ENCODES).
    :23     
    :24     **Mode `constellation`** — a corpus cross-reference consistency checker. Given a corpus root and one or
    :25     more paper paths, it builds an index (every `.md`'s current title + header version, plus REGISTRY
    :26     id→title/version/status rows) and, for each paper, flags: a **stale version** (a `vX.Y` cited next to a
    :27     `FILE.md` reference that ≠ the target's current header version), a **stale status** (`pending`/`awaiting`/…
    :28     language next to a REGISTRY id whose status is READY/RATIFIED/LANDED/…), and a **nonexistent target** (a
    :29     backticked `FILE.md` not on disk). It reads paths passed in; it embeds no corpus content.
    :30     
    :31     ## Usage
    :32     
    :33     ```
    :34     python rowgen.py generate      terminals.json               # -> records.json + a printed table
    :35     python rowgen.py diff          terminals.json table.md      # -> row-by-row flags (or 'ok')
    :36     python rowgen.py constellation <corpus-root> paper.md [...]  # -> cross-ref contradiction flags
    :37     ```
