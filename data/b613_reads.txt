    :63     ## 2. The Theorem
    :65     ### 2.1 Definitions
    :67     A *determined system* is one whose specification is finite, parameter-free, and uniquely defines the system. All properties trace to the specification. (The Riemann zeta function is determined: its specification — the integers, the quadratic form n², Poisson summation — leaves no free parameters.)
    :69     An *interface* is a structural coupling connecting two independent subsystems S₁ and S₂ within a determined system. The system decomposes as S = S₁ ⊕ I ⊕ S₂.
    :71     An interface I is *essential* if removing it destroys the system: the system cannot be defined without I.
    :73     An interface I is *universal* if it acts identically for all configurations of S₁ and S₂: its output does not depend on which specific states the subsystems occupy.
    :75     The *conservation rank* κ(P, I) ∈ [0, 1] measures how much information about a behavioral parameter P the interface I transmits. κ = 0 means I transmits no P-information. κ = 1 means I fully determines P.
    :77     ### 2.2 The Silence Principle
    :79     **Theorem.** Let X be a determined system with decomposition S = S₁ ⊕ I ⊕ S₂, where I is an essential interface. If I is universal, then for any behavioral parameter P that varies across configurations, κ(P, I) = 0.
    :81     *Proof.* Four steps:
    :83     1. I is *essential* → I is present in every configuration of X.
    :84     2. I is *universal* → I acts identically in every configuration.
    :85     3. Therefore I's contribution to any P-measurement is the same constant c across all configurations.
    :86     4. A constant contribution carries zero information about variation: κ(P, I) = 0. ∎
    :88     The proof has the logical structure: essential → universal → constant → silent. Each arrow is a single step of propositional reasoning. The theorem is elementary. Its consequences are not.
